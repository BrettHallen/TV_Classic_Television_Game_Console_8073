# TV Classic Television Game Console
An interesting form-factor for the retro-console category: a CRT-style television with a pair of 2.4GHz wireless controllers.<br>

The information I've been able to find:
- Box and PCBs are marked with item/model 8073
- A similar example has [FCC ID 2ARNX8073](/FCC_2ARNX8073.md) (thanks Michael!)

## Main Motherboard
- Marked as "DR-8073A-06V-2.8"
- Has ROM type JS28F256
- Has 16MHz crystal (X2) for the 2.4GHz controller (nRF24L01?)
- Has additional 26.601712MHz crystal (X1) for PAL video output
- Powered by 3xAAA or Micro-USB (5V)
- Has 36 test pads labelled J1 to J36
- Additional test pads: GND, VCC3V, GND1, VCC5V, A, EN
